# Convivencia

Este proyecto agradece preguntas, informes y contribuciones de personas con distintos niveles de experiencia.

- Debate ideas y comportamientos concretos con respeto.
- No publiques datos privados de otras personas.
- No se aceptan acoso, amenazas, discriminación ni ataques personales.
- Da contexto suficiente y evita exigir trabajo o respuestas inmediatas.

El mantenedor puede moderar contenido y limitar la participación para mantener un espacio de colaboración. Para comunicar una situación, abre una consulta sin datos sensibles o utiliza el canal privado de seguridad cuando corresponda.
