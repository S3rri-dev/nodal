# Solución de problemas

## macOS bloquea la apertura

La versión inicial tiene firma ad hoc, sin notarización. Consulta INSTALL.md y la documentación oficial de Apple. No utilices comandos para desactivar Gatekeeper.

## El calendario está vacío

Es el primer arranque previsto. Crea una asignatura y una sesión o importa un plan. La app no accede automáticamente al calendario de tu universidad.

## No aparece un PDF

Selecciona o repara la carpeta de materiales en Ajustes. Nodal guarda referencias, no copia colecciones docentes. Comprueba nombre, ubicación y permisos del archivo.

## El cronómetro se recupera pausado

Tras suspensión, cierre o un intervalo dudoso se excluye la ausencia. Revisa el registro y reanuda cuando corresponda; puedes añadir o corregir tiempo manualmente.

## No se ve el fondo o no hay animación

Reducir transparencia, Aumentar contraste y Reducir movimiento de macOS cambian la apariencia deliberadamente. Comprueba también Claro/Oscuro/Sistema en Ajustes.

## El XML se rechaza

Conserva el mensaje, revisa el esquema, los IDs y las referencias. Un fallo de validación no debe dejar cambios parciales. Puedes pegar una ruta completa si el selector nativo no habilita Abrir.

## Informar de un fallo

Incluye versión de Nodal y macOS, tipo de Mac, pasos y resultado esperado/observado. Utiliza datos ficticios. No adjuntes SQLite, credenciales o notas personales.
