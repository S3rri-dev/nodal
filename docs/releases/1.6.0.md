# Nodal 1.6.0

Primera publicación de Nodal para la comunidad: organización académica local para Mac con Apple Silicon.

## Incluye

- Calendario semanal, mensual y agenda, con línea horaria actual.
- Asignaturas, tareas y sesiones de estudio con cronómetro persistente.
- Calculadora con componentes editables y eliminables, guardado explícito y media circular.
- Dudas, revisión del estudio y replanificación con vista previa.
- Actualizaciones XML con conservación de registros y copia previa; intercambio de archivos ICS.
- Interfaz en español, temas claro/oscuro y acabado de vidrio translúcido.
- Inicio vacío, un plan XML ficticio y documentación de uso, privacidad, contribución y compilación.

## Descargar

Para utilizar la aplicación descarga **Nodal-1.6.0-arm64.dmg**, ábrelo y arrastra Nodal.app a Aplicaciones. El ZIP **Nodal-1.6.0-src.zip** es el código fuente para compilar, no el instalador.

El manifiesto relaciona cada artefacto con su commit y hash SHA-256. Descarga los adjuntos en la misma carpeta y ejecuta shasum -a 256 -c SHA256SUMS.txt para comprobarlos.

## Compatibilidad y límites

Apple Silicon; objetivo de compilación macOS 13 o posterior. Consulta las pruebas concretas en [VERIFICATION.md](https://github.com/S3rri-dev/nodal/blob/v1.6.0/docs/VERIFICATION.md).

**Firma ad hoc, sin Developer ID ni notarización.** macOS puede bloquear la primera apertura. Consulta [Instalación](https://github.com/S3rri-dev/nodal/blob/v1.6.0/docs/INSTALL.md), que enlaza el procedimiento oficial de Apple. No se distribuye una versión para Intel, Windows, Linux o iOS.
