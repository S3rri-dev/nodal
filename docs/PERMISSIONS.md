# Permisos de macOS

| Acción | Para qué se usa | Comportamiento |
| --- | --- | --- |
| Notificaciones | Recordatorios locales opcionales | Apagados por defecto; macOS solicita autorización al activarlos |
| Archivos elegidos | Importar planes, exportar/restaurar copias, seleccionar materiales | Selección o ruta introducida expresamente |
| Visor del sistema | Abrir un material seleccionado | Se abre la app asociada al archivo |

Nodal no solicita acceso a Apple Calendar, contactos, cámara, micrófono, grabación de pantalla ni Accesibilidad.

La aplicación inicial no está distribuida mediante App Sandbox. Los selectores de archivos no deben interpretarse como una garantía de aislamiento del proceso. Consulta PRIVACY.md y SECURITY.md.
