# Ayuda

1. Revisa [Primeros pasos](docs/GETTING_STARTED.md) y [Solución de problemas](docs/TROUBLESHOOTING.md).
2. Busca incidencias existentes.
3. Abre un [informe de error](https://github.com/S3rri-dev/nodal/issues/new/choose) con versión, macOS, arquitectura y pasos concretos.

Las respuestas no tienen un plazo garantizado. No adjuntes tu base SQLite ni un plan académico real a una incidencia pública. Puedes preparar un ejemplo ficticio mínimo.

Para problemas de seguridad, utiliza el canal privado descrito en SECURITY.md.
